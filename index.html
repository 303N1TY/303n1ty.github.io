    WikiBoosters
    
      
    Every Wikipedia article is a card. Rarity isn't rolled at random: it follows how much the article is read.
    
      
    
        
    type
    free trading-card game
    
        
    platforms
    iOS · Android · Web
    
        
    stack
    Expo · Rust · PostgreSQL · SQLite

    Rarity is read,
    not rolled.
    
      
    The more an article is read, the rarer its card. The Eiffel Tower is ultra rare, the Collatz conjecture is common, and the Earth itself is legendary. Readership moves every hour, so the game keeps moving with it.

    cards-api
    
          
    The whole catalogue is built from French Wikipedia dumps into a read-only SQLite file, served by a Rust API: search, booster draws, hour-by-hour trends.
    
        
    
        
    
          
    game-api
    
          
    Rust and PostgreSQL for everything that belongs to players: accounts, collections, trades, auctions, guilds and real-time duels.
    
        
    
        
    
          
    client
    
          
    One Expo codebase for iOS, Android and the web. Shared game rules live in a Rust crate used by both back ends.
